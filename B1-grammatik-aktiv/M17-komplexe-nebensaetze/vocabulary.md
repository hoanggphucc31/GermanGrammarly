# Vocabulary: Finalsätze, Doppelkonnektoren & Vergleichssätze

## Purpose Connectors
| German | English | 🇻🇳 |
|---|---|---|
| **um...zu** | in order to (same subject) | để mà (cùng chủ ngữ) |
| **damit** | so that (different subjects) | để cho / để mà (khác chủ ngữ) |

## Double Connectors (Doppelkonnektoren)
| German | English | 🇻🇳 |
|---|---|---|
| **entweder...oder** | either...or | hoặc...hoặc |
| **weder...noch** | neither...nor | không...cũng không |
| **nicht nur...sondern auch** | not only...but also | không chỉ...mà còn |
| **sowohl...als auch** | both...and | cả...lẫn |
| **zwar...aber** | indeed...but | tuy...nhưng |

## Comparison Words
| German | English | 🇻🇳 |
|---|---|---|
| **je...desto** | the more...the more | càng...càng |
| **je...umso** | the more...the more | càng...càng |
| **so...wie** | as...as | bằng...như |
| **Komparativ + als** | more...than | hơn...so với |

## Useful Adjective Pairs for je...desto
| Pair | Example |
|---|---|
| mehr / besser | Je mehr, desto besser. |
| älter / weiser | Je älter, desto weiser. |
| billiger / schlechter | Je billiger, desto schlechter. |
| länger / schwieriger | Je länger, desto schwieriger. |
| schneller / gefährlicher | Je schneller, desto gefährlicher. |
