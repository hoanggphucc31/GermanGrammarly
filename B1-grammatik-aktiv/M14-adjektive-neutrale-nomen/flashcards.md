# Flashcards: Adjektive als neutrale Nomen

> Print double-sided or use in Anki/Quizlet.

| Front (Prompt) | Back (Answer) |
|---|---|
| I wish you all the best! | Ich wünsche dir **alles Gute**! |
| Is there anything new? | Gibt es **etwas Neues**? |
| I did nothing special. | Ich habe **nichts Besonderes** gemacht. |
| He told a lot of interesting things. | Er hat **viel Interessantes** erzählt. |
| Did something bad happen? | Ist **etwas Schlimmes** passiert? |
| We bought everything necessary. | Wir haben **alles Notwendige** gekauft. |
| I don't have anything suitable to wear. | Ich habe **nichts Passendes** zum Anziehen. |
| [Grammar Rule] Ending after etwas/nichts/viel? | Capitalized Adjective + **es** (etwas Neues) |
| [Grammar Rule] Ending after alles? | Capitalized Adjective + **e** (alles Gute) |
| [Grammar Trap] alles Gutes OR alles Gute? | **alles Gute** (-e ending after alles!) |
