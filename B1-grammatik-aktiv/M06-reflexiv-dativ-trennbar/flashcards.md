# Module 06 — Flashcards: Reflexive Dativ & Dual Verbs

## Reflexive Dativ
| Front | Back |
|---|---|
| Why: "Ich wasche **mich**" BUT "Ich wasche **mir** die Hände"? | Because "die Hände" is a direct Akkusativ object, pushing the reflexive pronoun to Dativ. |
| Reflexive Dativ for *ich* and *du*? | **mir** and **dir** |
| Translate: *Don't worry!* (du form) | Mach **dir** keine Sorgen! |
| Translate: *I wish for a bike.* | Ich wünsche **mir** ein Fahrrad. |

## Trennbar vs Nicht Trennbar (Dual Prefixes)
| Front | Back |
|---|---|
| Which 5 prefixes can be BOTH separable and inseparable? | durch-, über-, um-, unter-, wieder- |
| If a dual prefix verb is **literal** (concrete), is it usually separable or inseparable? | **Separable** (trennbar). Example: *umsteigen* (change trains). |
| If a dual prefix verb is **abstract** (figurative), is it usually separable or inseparable? | **Inseparable** (nicht trennbar). Example: *übersetzen* (translate). |
| Perfekt of *übersetzen* (translate)? | hat **übersetzt** (Inseparable = no 'ge') |
| Perfekt of *unterschreiben* (sign)? | hat **unterschrieben** (Inseparable = no 'ge') |
| Perfekt of *umsteigen* (transfer)? | ist **umgestiegen** (Separable = gets 'ge') |
