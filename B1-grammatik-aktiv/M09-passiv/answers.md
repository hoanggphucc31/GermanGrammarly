# Module 09 — Answers: Passiv

---

## Part A: Passiv Präsens
1. Die Haare **werden geschnitten**. (Plural -> werden)
2. Die Autos **werden produziert**. (Plural -> werden)
3. Hier **wird** Spanisch **gesprochen**.
4. Das Zimmer **wird gereinigt**. (Oder: **geputzt**)
5. Mein Fahrrad **wird vom** Mechaniker **repariert**. (von dem = vom)

## Part B: Passiv Präteritum
1. Die Musik **wurde von** Mozart **komponiert**.
2. Mein Auto **wurde gestohlen**.
3. Das Stadion **wurde** im Jahr 2000 **gebaut**.
4. Der Patient **wurde operiert**.

## Part C: Passiv Perfekt
1. Das Fenster **ist geöffnet worden**.
2. Ich **bin eingeladen worden**. ("mich" -> "ich" because it becomes the subject).
3. Die Rechnungen **sind bezahlt worden**. (Plural -> sind)
4. Die E-Mail **ist geschrieben worden**.

## Part D: Which Tense is it?
1. Das Haus **wird** verkauft. → **Präsens** (wird + PP2)
2. Das Buch **wurde** 1990 geschrieben. → **Präteritum** (wurde + PP2)
3. Die Tür **ist** geschlossen **worden**. → **Perfekt** (ist + PP2 + worden)
4. Die Fehler **werden** korrigiert. → **Präsens** (werden + PP2)
5. Der Kuchen **ist** gegessen **worden**. → **Perfekt** (ist + PP2 + worden)

## Part E: "worden" vs. "geworden"
1. Er ist letztes Jahr Vater **geworden**. (He became a father -> Active "werden")
2. Das Auto ist repariert **worden**. (The car has been repaired -> Passive Perfekt)
3. Es ist plötzlich sehr kalt **geworden**. (It became cold -> Active "werden")
4. Die Hausaufgaben sind gemacht **worden**. (The homework has been done -> Passive Perfekt)

## Part F: Passiv mit Modalverb
1. Das Fenster **muss geschlossen werden**. (Modal "muss" stays conjugated; Partizip II + werden at the end)
2. Das Problem **kann** leicht **gelöst werden**. (Modal "kann" stays conjugated)
3. Das Foto **darf** nicht **kopiert werden**. ("darf nicht" = prohibition)
4. Die Straße **musste gesperrt werden**. (Präteritum: "musste" instead of "muss")
5. Ich weiß, dass der Ausweis **vorgezeigt werden muss**. (Nebensatz: Partizip II + werden + Modal at the very end)
