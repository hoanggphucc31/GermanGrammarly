# Module 09 — Vocabulary: Passiv

| Infinitive | Partizip II | 🇻🇳 | Passive Example (Präsens) |
|---|---|---|---|
| **bauen** | gebaut | xây dựng | Das Haus wird gebaut. |
| **eröffnen** | eröffnet | khai trương | Der Flughafen wird eröffnet. |
| **gründen** | gegründet | thành lập | Die Firma wird gegründet. |
| **operieren** | operiert | phẫu thuật | Der Patient wird operiert. |
| **produzieren**| produziert | sản xuất | Die Autos werden produziert. |

## Important Grammar Terms
| German | 🇻🇳 | Explanation |
|---|---|---|
| **Aktiv** | Thể chủ động | The subject does the action (*Er baut das Haus.*) |
| **Passiv** | Thể bị động | The subject receives the action (*Das Haus wird gebaut.*) |
| **Vorgangspassiv**| Bị động chỉ quá trình | Focuses on the action happening (`werden` + PP2). (As opposed to Zustandspassiv `sein` + PP2, which describes a state). |
| **Täter** | Tác nhân | The person doing the action (introduced by `von + Dativ` in a passive sentence). |

## Prepositions for the Agent
| Preposition | 🇻🇳 | Usage |
|---|---|---|
| **von (+ Dativ)** | bởi (ai đó) | Used for people or institutions. *Das Buch wurde von Goethe geschrieben.* |
| **durch (+ Akkusativ)** | bởi (cái gì / do đâu) | Used for tools, forces of nature, or causes. *Das Haus wurde durch den Sturm zerstört.* |

## Passiv mit Modalverb — Key Phrases
| Modal Pattern | 🇻🇳 | Example |
|---|---|---|
| **muss ... werden** | phải được (làm gì) | Die Rechnung muss bezahlt werden. |
| **kann ... werden** | có thể được (làm gì) | Das kann leicht repariert werden. |
| **soll ... werden** | nên được (làm gì) | Das Fenster soll geputzt werden. |
| **darf nicht ... werden** | không được phép (làm gì) | Das Dokument darf nicht kopiert werden. |
| **musste ... werden** | đã phải được (quá khứ) | Das Auto musste abgeschleppt werden. |
