# Module 09 — Flashcards: Passiv

## Passive Structures
| Front | Back |
|---|---|
| How do you form the Passiv Präsens? | **werden** (conjugated) + **Partizip II** |
| How do you form the Passiv Präteritum? | **wurde** (conjugated) + **Partizip II** |
| How do you form the Passiv Perfekt? | **sein** (ist/sind) + **Partizip II** + **worden** |
| How do you say "by" a person in a passive sentence? | **von** + Dativ (e.g., von dem Arzt = vom Arzt) |

## Tense Identification
| Front | Back |
|---|---|
| *Das Haus wird gebaut.* (Which tense?) | **Präsens** (Present) |
| *Das Haus wurde gebaut.* (Which tense?) | **Präteritum** (Simple Past) |
| *Das Haus ist gebaut worden.* (Which tense?) | **Perfekt** (Present Perfect) |

## Trap: worden vs geworden
| Front | Back |
|---|---|
| He became a doctor. (Er ist Arzt ________.) | **geworden** (Active = became) |
| The patient has been examined. (Der Patient ist untersucht ________.) | **worden** (Passive = has been done) |

## Translation Practice
| Front | Back |
|---|---|
| *Hier wird Deutsch gesprochen.* | German is spoken here. |
| *Mein Fahrrad ist gestohlen worden.* | My bike has been stolen. |
| *Ich wurde gestern operiert.* | I was operated on yesterday. |

## Passiv mit Modalverb
| Front | Back |
|---|---|
| How do you form Passiv mit Modalverb? | **Modalverb** (conjugated) + **Partizip II** + **werden** (Infinitiv at the end) |
| Translate: "The button must be pressed." | Der Knopf **muss gedrückt werden**. |
| Translate: "The window must not be opened." | Das Fenster **darf nicht geöffnet werden**. |
| How does word order change in a Nebensatz? | Modal goes to the very end: *...dass der Knopf **gedrückt werden muss**.* |
| Rewrite as Passiv: "Man muss den Ausweis zeigen." | Der Ausweis **muss gezeigt werden**. |
