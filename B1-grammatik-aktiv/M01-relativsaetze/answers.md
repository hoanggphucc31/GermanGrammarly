# Module 01 — Answers: Relativsätze

---

## Part A: Nominativ

1. Das ist der Lehrer, **der** Deutsch unterrichtet.
2. Ich kenne das Mädchen, **das** so schön singt.
3. Die Frau, **die** nebenan wohnt, ist meine Nachbarin.
4. Das sind die Kinder, **die** im Garten spielen.
5. Das ist das Restaurant, **das** die beste Pizza hat.
6. Der Mann, **der** vielen Menschen hilft, ist Arzt.

## Part B: Akkusativ

1. Das ist der Film, **den** ich gestern gesehen habe. (m Akk)
2. Das ist die Tasche, **die** ich gekauft habe. (f Akk = Nom)
3. Wo ist das Buch, **das** ich dir gegeben habe? (n Akk = Nom)
4. Kennst du den Mann, **den** wir auf der Party getroffen haben?
5. Das sind die Schuhe, **die** ich kaufen möchte. (pl Akk)
6. Das ist das Kleid, **das** Maria getragen hat.

## Part C: Dativ

1. Das ist der Kollege, **dem** ich geholfen habe. (m Dat)
2. Das ist die Lehrerin, **der** ich gedankt habe. (f Dat)
3. Das ist das Kind, **dem** ich ein Buch geschenkt habe. (n Dat)
4. Das sind die Leute, **denen** ich geschrieben habe. (pl Dat → denen!)
5. Der Mann, **dem** ich mein Auto geliehen habe, ist mein Freund.

## Part D: With Prepositions

1. ..., **mit dem** ich gesprochen habe. (mit + Dat, Mann = m → dem)
2. ..., **auf die** ich mich vorbereite. (auf + Akk, Prüfung = f → die)
3. ..., **in der** ich aufgewachsen bin. (in + Dat, Stadt = f → der)
4. ..., **mit dem** ich ins Kino gehe. (mit + Dat, Freund = m → dem)
5. ..., **über die** wir diskutiert haben. (über + Akk, Probleme = pl → die)

## Part E: Mixed

1. ..., **den** ich verloren habe. (Schlüssel = m, Akk → den)
2. Der Mann, **der** dort steht, ... (m, Nom → der)
3. Die Frau, **der** ich geholfen habe, ... (f, Dat → der; helfen + Dat)
4. ..., in **dem** wir uns treffen. (Café = n, in + Dat → dem)
5. Die Kinder, **die** im Park spielen, ... (pl, Nom → die)
6. ..., **den** ich geschrieben habe. (Brief = m, Akk → den)
