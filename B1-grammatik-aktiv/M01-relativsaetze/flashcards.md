# Module 01 — Flashcards: Relativsätze

---

## Case Selection Cards

| Front | Back |
|---|---|
| Relative pronoun = Subject → ? | **Nominativ** (der/das/die/die) |
| Relative pronoun = Direct Object → ? | **Akkusativ** (den/das/die/die) |
| After helfen/danken/geben → ? | **Dativ** (dem/dem/der/denen) |
| After a preposition → ? | Case depends on the preposition! |

---

## Pronoun Cards

| Front | Back |
|---|---|
| m + Nom → ? | **der** |
| m + Akk → ? | **den** |
| m + Dat → ? | **dem** |
| f + Nom/Akk → ? | **die** |
| f + Dat → ? | **der** |
| n + Nom/Akk → ? | **das** |
| n + Dat → ? | **dem** |
| pl + Nom/Akk → ? | **die** |
| pl + Dat → ? | **denen** ⚠️ |

## Cloze Cards

| Front | Back |
|---|---|
| Der Mann, ___ Deutsch spricht, ... (Nom m) | **der** |
| Der Mann, ___ ich kenne, ... (Akk m) | **den** |
| Die Frau, ___ ich geholfen habe, ... (Dat f) | **der** |
| Die Stadt, in ___ ich wohne, ... (in + Dat f) | **der** |
| Die Leute, ___ ich geschrieben habe, ... (Dat pl) | **denen** |
