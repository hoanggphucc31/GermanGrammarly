|---|---|---|
| **folgend** | folgen | following |

| **wachsend** | wachsen | growing |
| **laufend** | laufen | running/ongoing |
| **entsprechend** | entsprechen | corresponding |
| **fehlend** | fehlen | missing |
| **überraschend** | überraschen | surprising |
| **entscheidend** | entscheiden | decisive |
| **steigend** | steigen | rising |

## Partizip II as Adjective (Contrast)
| Partizip I (Active) | Partizip II (Passive) |
|---|---|
| kochend (boiling) | gekocht (boiled) |
| singend (singing) | gesungen (sung) |
| schlafend (sleeping) | eingeschlafen (fallen asleep) |
| lesend (reading) | gelesen (read) |
| brennend (burning) | verbrannt (burned) |
