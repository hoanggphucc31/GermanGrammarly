# Answers: Adjektivdeklination (Nullartikel) & Partizip I als Adjektiv

## Exercise 1
1. Ich trinke gern kalt**es** Bier. *(Neutrum Akk Nullartikel → -es)*
2. Frisch**e** Luft tut gut. *(Feminin Nom Nullartikel → -e)*
3. Mit gut**en** Freunden feiert man am besten. *(Plural Dat → -en)*
4. Heiß**er** Kaffee schmeckt am Morgen besonders gut. *(Maskulin Nom Nullartikel → -er)*
5. Sie isst frisch**es** Obst. *(Neutrum Akk Nullartikel → -es)*
6. In deutsch**en** Städten gibt es viele Museen. *(Plural Dat → -en)*
7. Er trägt teur**e** Schuhe. *(Plural Akk Nullartikel → -e)*
8. Klein**e** Kinder brauchen viel Schlaf. *(Plural Nom Nullartikel → -e)*

## Exercise 2
1. lesen → **lesend**
2. tanzen → **tanzend**
3. weinen → **weinend**
4. lachen → **lachend**
5. wachsen → **wachsend**
6. spielen → **spielend**

## Exercise 3
1. der **schlafende** Hund *(m, Nom, best. Artikel → -e)*
2. ein **wachsendes** Problem *(n, Nom, unbest. Artikel → -es)*
3. die **kommende** Woche *(f, Nom, best. Artikel → -e)*
4. mit **laufendem** Motor *(m, Dat, Nullartikel → -em)*
5. die **folgenden** Informationen *(pl, Nom, best. Artikel → -en)*

## Exercise 4
1. das **kochende** Wasser *(Partizip I — active: it IS boiling)*
2. das **gekochte** Ei *(Partizip II — passive/completed: it HAS BEEN boiled)*
3. der **singende** Vogel *(Partizip I — active: it IS singing)*
4. das **gesungene** Lied *(Partizip II — passive: it HAS BEEN sung)*
5. die **geöffnete** Tür *(Partizip II — passive: it HAS BEEN opened)*
