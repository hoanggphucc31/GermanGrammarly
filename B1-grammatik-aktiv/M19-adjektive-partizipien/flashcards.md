# Flashcards: Adjektivdeklination (Nullartikel) & Partizip I als Adjektiv

| Front (Prompt) | Back (Answer) |
|---|---|
| German beer (no article, Nom n) | **Deutsches** Bier |
| Cold coffee (no article, Nom m) | **Kalter** Kaffee |
| Fresh milk (no article, Nom f) | **Frische** Milch |
| Small children (no article, Nom pl) | **Kleine** Kinder |
| [Rule] Nullartikel ending pattern? | Same as definite article: der→-er, das→-es, die→-e, den→-en, dem→-em |
| How to form Partizip I? | Infinitiv + **d**: singen → singend, laufen → laufend |
| the singing bird | der **singende** Vogel |
| a growing problem | ein **wachsendes** Problem |
| the coming week | die **kommende** Woche |
| [Trap] Partizip I vs II: kochendes Wasser vs gekochtes Ei? | kochend = boiling (active NOW), gekocht = boiled (DONE) |
| the following information | die **folgenden** Informationen |
