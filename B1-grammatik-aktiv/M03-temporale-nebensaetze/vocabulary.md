# Module 03 — Vocabulary: Temporale Nebensätze

---

## 1 · Signal Words for als (One-Time Past)

| German | 🇻🇳 |
|---|---|
| **zum ersten Mal** | lần đầu tiên |
| **als Kind** | khi còn nhỏ |
| **eines Tages** | một ngày nọ |
| **plötzlich** | bất ngờ |
| **damals** | hồi đó |

| German | 🇻🇳 |
|---|---|

| **jedes Mal** | mỗi lần |
| **oft** | thường |
| **meistens** | hầu hết |
| **manchmal** | đôi khi |
