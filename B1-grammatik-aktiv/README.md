## Overview

This directory contains B1-level grammar modules covering **Kapitel 49-80** of *Grammatik Aktiv A1-B1*.

Modules M01-M03 were originally created as supplementary content but have since been **remapped** to their corresponding textbook chapters (Kap. 68-72). Only M04 (Modalpartikeln) remains as a truly supplementary, exam-oriented module.

## Module Architecture

Each module contains 6 files:

| File | Purpose |
|---|---|
| `lesson.md` | Core grammar explanation with examples and dialogues |
| `exercises.md` | Graded practice exercises |
| `answers.md` | Answer key with explanations |
| `vocabulary.md` | Key words grouped by theme |
| `flashcards.md` | Front/back cards for memorization |
| `exam-tips.md` | Goethe B1 exam strategies |
