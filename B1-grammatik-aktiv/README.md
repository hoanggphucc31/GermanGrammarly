> **Level:** B1 (Intermediate)
> **Textbook:** Grammatik Aktiv A1-B1 (Cornelsen) + Supplementary B1 Grammar
> **Format:** Bilingual English-Vietnamese 🇬🇧🇻🇳

---

## Overview

This directory contains B1-level grammar modules. These modules cover **core B1 grammar topics** that are essential for Goethe B1 certification. 

> ⚠️ **Important Note:** The topics in these modules (Relativsätze, Infinitiv mit/ohne zu, als/wenn, Modalpartikeln) are standard B1 grammar content but are **not directly mapped** to specific chapters of *Grammatik Aktiv A1-B1*. The book's chapters 43-50 cover different topics (Positionsadverbien, Partikeln, Komposita, Wortbildung, Genusregeln, Präteritum, Plusquamperfekt). These modules serve as **supplementary B1 instruction** to complement the textbook.
