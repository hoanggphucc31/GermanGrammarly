# Module 04 — Vocabulary: Modalpartikeln & Zeitadverbien

---

## 1 · Modalpartikeln

| Particle | Function | Example | 🇻🇳 |
|---|---|---|---|
| **denn** | Interest (questions) | Wie heißt du **denn**? | thế/vậy/à |
| **mal** | Soften request | Hilf mir **mal**! | một chút/cái |
| **doch** | Emphasis / encourage / contradict | Das ist **doch** klar! | mà/chứ |
| **ja** | Obvious/surprising fact | Das ist **ja** toll! | rõ ràng là |
| **eigentlich** | Actually | **Eigentlich** wollte ich... | thực ra |
| **eben/halt** | Resignation | Das ist **eben** so. | thôi thì |

## 2 · Zeitadverbien

| Adverb | Meaning | 🇻🇳 |
|---|---|---|
| **schon** | already | đã (sớm hơn kỳ vọng) |
| **erst** | only / not until | mới (muộn hơn kỳ vọng) |
| **noch** | still | vẫn còn |
| **nicht mehr** | not anymore | không còn nữa |
| **noch nicht** | not yet | vẫn chưa |
| **noch nie** | never (yet) | chưa bao giờ |
| **schon mal** | ever | đã từng |
| **schon immer** | always (since forever) | luôn luôn |
