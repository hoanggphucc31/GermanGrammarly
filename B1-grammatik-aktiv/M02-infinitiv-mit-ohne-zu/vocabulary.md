# Module 02 — Vocabulary: Infinitiv mit/ohne zu

---

## 1 · Verbs That Require "zu"

| German | 🇻🇳 |
|---|---|
| **anfangen** | bắt đầu |
| **aufhören** | ngừng |
| **versuchen** | cố gắng |
| **vergessen** | quên |
| **planen** | lên kế hoạch |
| **vorhaben** | dự định |
| **hoffen** | hy vọng |
| **sich freuen** | vui mừng |
| **bitten** | yêu cầu, nhờ |

## 2 · Verbs Without "zu"

| German | 🇻🇳 |
|---|---|
| **können** | có thể |
| **müssen** | phải |
| **dürfen** | được phép |
| **sollen** | nên |
| **wollen** | muốn |
| **lassen** | để cho / cho làm |
| **hören** | nghe |
| **sehen** | nhìn thấy |
| **gehen** | đi |

## 3 · Useful Expressions

| German | 🇻🇳 |
|---|---|
| **Es ist wichtig, ... zu ...** | Quan trọng là... |
| **Es ist möglich, ... zu ...** | Có thể... |
| **Es ist schwer, ... zu ...** | Khó để... |
| **Ich habe Lust, ... zu ...** | Tôi muốn... |
| **Ich habe keine Zeit, ... zu ...** | Tôi không có thời gian... |
| **um ... zu ...** | để mà... |
| **ohne ... zu ...** | mà không... |
| **(an)statt ... zu ...** | thay vì... |
