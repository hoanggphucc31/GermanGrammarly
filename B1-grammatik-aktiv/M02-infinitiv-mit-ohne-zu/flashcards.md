# Module 02 — Flashcards: Infinitiv mit/ohne zu

---

## Decision Cards

| Front | Back |
|---|---|
| After Modalverben → zu? | **NO** (Ich kann schwimmen.) |
| After lassen → zu? | **NO** (Ich lasse reparieren.) |
| After hören/sehen → zu? | **NO** (Ich höre ihn singen.) |
| After gehen/fahren/kommen → zu? | **NO** (Wir gehen schwimmen.) |
| After versuchen/hoffen/planen → zu? | **YES** (Ich versuche, zu lernen.) |
| After adj + sein → zu? | **YES** (Es ist wichtig, zu üben.) |
| Purpose (in order to) → ? | **um ... zu** |
