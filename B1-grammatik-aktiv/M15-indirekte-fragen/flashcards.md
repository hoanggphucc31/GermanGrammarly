# Flashcards: Indirekte Fragen

> Print double-sided or use in Anki/Quizlet.

| Front (Prompt) | Back (Answer) |
|---|---|
| Can you tell me where the station is? | **Können Sie mir sagen, wo** der Bahnhof **ist**? |
| Do you know if he is coming? | **Wissen Sie, ob** er **kommt**? |
| May I ask why you are late? | **Darf ich fragen, warum** du zu spät **bist**? |
| I would like to know how much it costs. | **Ich möchte gern wissen, wie viel** das **kostet**. |
| I don't know when the train departs. | **Ich weiß nicht, wann** der Zug **abfährt**. |
| Could you (please) tell me if there is WiFi here? | **Könnten Sie mir (bitte) sagen, ob** es hier WLAN **gibt**? |
| [Grammar] What happens to the verb in an indirect question? | It goes to the **END** of the sentence. |
| [Grammar Trap] "wenn" vs "ob" for yes/no questions? | Use **ob**! (wenn is for conditions/time). |
| [Punctuation Rule] Indirect questions | Always separate with a **comma** before the question word / ob. |
