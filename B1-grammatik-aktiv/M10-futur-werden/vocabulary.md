| Person | Form | 🇻🇳 |
|---|---|---|
| **ich** | werde | tôi sẽ / trở thành / bị... |
| **du** | **wirst** | (vowel change e -> i) |
| **er/sie/es** | **wird** | (vowel change e -> i, no 't' ending!) |
| **wir** | werden | |
| **ihr** | werdet | |

## Words for Assumptions (Vermutungen)
| German | 🇻🇳 | Example (Futur I) |
|---|---|---|
| **wohl** | có lẽ (rất khả thi) | Er wird wohl zu Hause sein. |
| **wahrscheinlich** | có thể / xác suất cao | Sie wird wahrscheinlich im Stau stehen. |
| **vielleicht** | có lẽ (50/50) | Das wird vielleicht klappen. |

## False Friends: The "W" Trap
| English Word | German Translation | Why it's a trap |
|---|---|---|
| **will** (future) | **werden** | Never translate "I will" to "Ich will". It means "Ich werde". |
| **want** (desire) | **wollen** | "Ich will" means "I want". |
| **become** (change) | **werden** | Never translate "I become" to "Ich bekomme". That means "I receive". |
| **get/receive** | **bekommen** | "Ich bekomme ein Geschenk" = I receive a gift. |
