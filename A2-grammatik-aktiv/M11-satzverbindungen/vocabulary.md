# Module 11 — Vocabulary: Satzverbindungen

---

## 1 · Position 0 Konjunktionen

| German | 🇻🇳 | Function |
|---|---|---|
| **und** | và | Addition |
| **oder** | hoặc | Alternative |
| **aber** | nhưng | Contrast |
| **denn** | vì, bởi vì | Reason |
| **sondern** | mà là | Correction (after negation) |

## 2 · Position 1 Adverbien

| German | 🇻🇳 | Function |
|---|---|---|
| **deshalb** | vì vậy | Result |
| **deswegen** | vì vậy | Result (= deshalb) |
| **trotzdem** | tuy nhiên | Unexpected result |
| **sonst** | nếu không thì | Warning |
| **dann** | sau đó | Sequence |
| **danach** | sau đó | Sequence (= dann) |

## 3 · Useful Phrases

| German | 🇻🇳 |
|---|---|
| **Zuerst... dann... danach...** | Đầu tiên... rồi... sau đó... |
| **Nicht A, sondern B.** | Không phải A, mà là B. |
| **Beeil dich! Sonst...** | Nhanh lên! Nếu không thì... |
