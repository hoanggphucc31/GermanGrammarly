# Module 11 — Answers: Satzverbindungen

---

## Part A: Position 0

1. ..., **aber** ich habe kein Geld. (contrast)
2. ... Pizza **oder** Pasta? (alternative)
3. ... Deutsch, **denn** er arbeitet in Berlin. (reason)
4. ... nicht Englisch, **sondern** Französisch. (correction after negation)
5. Ich koche **und** du räumst auf. (addition)
6. ... teuer, **aber** die Lage ist perfekt. (contrast)

## Part B: Position 1

1. **Deshalb** bleibe ich zu Hause. (result)
2. **Trotzdem** gehe ich heute joggen. (unexpected!)
3. **Sonst** verpassen wir den Zug. (otherwise)
4. **Dann** frühstücke ich. (sequence)
5. **Deshalb** nehme ich eine Tablette. (result)
6. **Danach** hat er eine Party gemacht. (after that)

## Part C: Word Order

1. Deshalb **bleibe ich** zu Hause. (Pos. 1 → inversion)
2. ..., aber **ich gehe** spazieren. (Pos. 0 → normal)
3. Sonst **bestehst du** die Prüfung nicht. (Pos. 1 → inversion)
4. Trotzdem **arbeitet er** weiter. (Pos. 1 → inversion)
5. Dann **gehe ich** zur Arbeit. (Pos. 1 → inversion)

## Part D: denn or weil?

1. ..., **denn** ich **bin** krank. (Pos. 0 → normal word order)
2. ..., **weil** ich krank **bin**. (Nebensatz → verb at end)
3. ..., **denn** er **arbeitet** in München. (Pos. 0 → normal)
4. ..., **weil** sie keine Zeit **hat**. (Nebensatz → verb at end)
5. ..., **denn** es **regnet**. / ..., **weil** es **regnet**. (both work here)

## Part E: Mixed

1. ..., **aber** ich muss arbeiten. (contrast)
2. **Deshalb** fährt er mit dem Bus. (result → inversion)
3. ... Kaffee **oder** Tee? (alternative)
4. ... nicht mein Buch, **sondern** deins. (correction)
5. **Sonst** bekommst du Karies. (otherwise → inversion)
6. **Trotzdem** sind wir schwimmen gegangen. (unexpected → inversion)
