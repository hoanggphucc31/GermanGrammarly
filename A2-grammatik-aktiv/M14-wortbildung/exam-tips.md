# Module 14 — Exam Tips: Wortbildung

> 🎯 **Goethe A2:** Understanding compound words helps in **Lesen** (guessing unknown words). Suffix knowledge helps determine gender for Schreiben.

## Key Tips
1. **Last word = gender + core meaning** → der Kinder**arzt** (der Arzt)
2. **-chen/-lein = always das** → das Mädchen, das Brötchen
3. **-ung = always die** → die Wohnung, die Übung
4. **Break long words apart** to guess meaning in Lesen!

> 🇻🇳 *Mẹo: Khi gặp từ dài trong bài đọc, hãy tách ra thành 2-3 phần nhỏ. Ví dụ: Kranken-haus-aufenthalt = bệnh viện + ở = thời gian nằm viện.*
