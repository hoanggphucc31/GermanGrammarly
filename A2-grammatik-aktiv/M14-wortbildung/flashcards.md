# Module 14 — Flashcards: Wortbildung

| Front | Back |
|---|---|
| -chen / -lein → gender? | Always **das** |
| -ung → gender? | Always **die** |
| -er (person) → gender? | **der** |
| -in (female person) → gender? | **die** |
| Last word in Kompositum = ? | Determines meaning AND gender |
| Katze + chen → ? | **das Kätzchen** (+ Umlaut!) |
