# Module 07 — Exam Tips: Wechselpräpositionen

> 🎯 **Goethe A2:** Wechselpräpositionen are tested through Bildbeschreibung (picture description), room descriptions, and direction-giving.

---

## How This Grammar Appears

| Section | What to Watch |
|---|---|
| **Hören** | Listening for object positions: "Die Lampe steht **auf dem** Tisch." |
| **Lesen** | Reading room/apartment descriptions. |
| **Schreiben** | Describing your room or apartment in an email. |
| **Sprechen** | Bildbeschreibung: "**Auf dem** Bild sehe ich... **Neben dem** Tisch steht..." |

## Key Tips

1. **Bildbeschreibung Template (Sprechen)**
   * Start with: *Auf dem Bild sehe ich...*
   * Then use location phrases:
   * ***Auf dem** Tisch steht eine Lampe.*
   * ***An der** Wand hängt ein Bild.*
   * ***Neben dem** Schrank steht ein Regal.*
   * ***Unter dem** Tisch liegt eine Katze.*

2. **The im/ins Shortcut**
   * If you hear/read **im** → someone IS somewhere (Wo?)
   * If you hear/read **ins** → someone IS GOING somewhere (Wohin?)
   * Same for **am/ans**.

3. **The Verb Pair Trap**
   * Don't confuse action and state verbs:
   * ❌ *Ich **stehe** das Glas auf den Tisch.* (stehen = state!)
   * ✅ *Ich **stelle** das Glas auf den Tisch.* (stellen = action!)

4. **Room Description for Schreiben**
   * Typical email task: "Describe your new room."
   * Use: stehen + auf/neben/vor, liegen + auf/unter, hängen + an/über.
   * *In meinem Zimmer steht das Bett **an der** Wand. **Neben dem** Bett steht ein Schrank.*

> 🇻🇳 *Mẹo: Khi mô tả phòng trong bài thi, hãy đi theo chiều kim đồng hồ (từ cửa → tường trái → tường đối diện → tường phải). Dùng "neben", "vor", "hinter", "über", "unter" để nối các đồ vật lại.*
