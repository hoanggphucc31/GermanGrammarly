# Module 07 — Answers: Wechselpräpositionen

---

## Part A: Wo? or Wohin?

1. Ich gehe in **den** Supermarkt. → **Wohin?** (Akkusativ — movement)
2. Ich bin in **dem** / **im** Supermarkt. → **Wo?** (Dativ — static)
3. Die Katze liegt auf **dem** Sofa. → **Wo?** (Dativ — liegen = state)
4. Die Katze springt auf **das** Sofa. → **Wohin?** (Akkusativ — movement)
5. Das Bild hängt an **der** Wand. → **Wo?** (Dativ — hängen = state)
6. Ich hänge das Bild an **die** Wand. → **Wohin?** (Akkusativ — action)
7. Er steht vor **der** Tür. → **Wo?** (Dativ — stehen = state)
8. Er geht vor **die** Tür. → **Wohin?** (Akkusativ — movement)

## Part B: Fill in the Article

1. in + **dem** (Dat) → contracted to **im**
2. in + **das** (Akk) → contracted to **ins**
3. auf **dem** Tisch (Wo? Dat m)
4. auf **den** Tisch (Wohin? Akk m)
5. neben **dem** Bett (Wo? Dat n)
6. neben **das** Bett (Wohin? Akk n)
7. auf **dem** Stuhl (Wo? Dat m)
8. auf **den** Stuhl (Wohin? Akk m)

## Part C: Contractions

1. Ich bin **im** Kino. (in + dem)
2. Ich gehe **ins** Kino. (in + das)
3. Er steht **am** Fenster. (an + dem)
4. Sie geht **ans** Fenster. (an + das)
5. Wir fahren **ans** Meer. (an + das)

## Part D: Choose the Verb

1. Die Flasche **steht** auf dem Tisch. (state → stehen)
2. Ich **stelle** die Flasche auf den Tisch. (action → stellen)
3. Das Buch **liegt** auf dem Schreibtisch. (state → liegen)
4. Ich **lege** das Buch auf den Schreibtisch. (action → legen)
5. Er **setzt** sich auf den Stuhl. (action → setzen)
6. Er **sitzt** auf dem Stuhl. (state → sitzen)

## Part E: Room Description

1. Das Bild hängt **an der** Wand. (Wo? die Wand → der)
2. Der Stuhl steht **vor dem** Schreibtisch. (Wo? der Schreibtisch → dem)
3. Die Lampe steht **auf dem** Tisch. (Wo? der Tisch → dem)
4. Die Schuhe liegen **unter dem** Bett. (Wo? das Bett → dem)
5. Der Schrank steht **neben der** Tür. (Wo? die Tür → der)
6. Die Katze sitzt **zwischen dem** Stuhl **und dem** Sofa. (Wo? Dat for both)
