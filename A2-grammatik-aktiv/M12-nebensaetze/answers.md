# Module 12 — Answers: Nebensätze

---

## Part A: weil
1. ..., weil ich krank **bin**.
2. ..., weil er in München **arbeitet**.
3. ..., weil sie keine Zeit **hat**.
4. ..., weil es **regnet**.
5. ..., weil ich keinen Hunger **habe**.
6. ..., weil er schlecht geschlafen **hat**.

## Part B: dass
1. ..., **dass** Deutsch interessant **ist**.
2. ..., **dass** du morgen **kommst**.
3. ..., **dass** er keine Zeit **hat**.
4. ..., **dass** das richtig **ist**.
5. ..., **dass** die Prüfung schwer **ist**.

## Part C: wenn
1. **Wenn** das Wetter schön **ist**, gehe ich spazieren.
2. Ruf mich an, **wenn** du Zeit **hast**.
3. **Wenn** ich müde **bin**, trinke ich Kaffee.
4. **Wenn** es **regnet**, bleibe ich zu Hause.
5. **Wenn** du **kommst**, bringe Brot mit.

## Part D: ob
1. ..., **ob** er morgen **kommt**.
2. ..., **ob** sie Zeit **hat**.
3. ..., **ob** das richtig **ist**.
4. ..., **ob** du kommen **kannst**?
5. ..., **ob** es morgen **regnet**.

## Part E: Mixed
1. ..., **weil** ich krank **bin**. (reason)
2. ..., **dass** er morgen **kommt**. (statement)
3. **Wenn** du Lust **hast**, können wir... (condition)
4. ..., **ob** der Laden offen **ist**? (yes/no)
5. ..., **dass** die Stadt schön **ist**. (opinion)
6. **Wenn** es **regnet**, **bleibe** ich zu Hause. (condition + inversion)
