# Module 12 — Vocabulary: Nebensätze

---

## 1 · Subordinating Conjunctions

| German | 🇻🇳 | Function |
|---|---|---|
| **weil** | vì | Reason |
| **dass** | rằng | Statement/opinion |
| **wenn** | khi / nếu | Condition / time |
| **ob** | liệu có...không | Indirect yes/no question |

## 2 · Verbs Before dass

| German | 🇻🇳 |
|---|---|
| **finden** | thấy, nhận thấy |
| **glauben** | tin |
| **hoffen** | hy vọng |
| **sagen** | nói |
| **wissen** | biết |
| **denken** | nghĩ |

## 3 · Useful Phrases

| German | 🇻🇳 |
|---|---|
| **Ich finde, dass...** | Tôi thấy rằng... |
| **Ich weiß nicht, ob...** | Tôi không biết liệu... |
| **Wenn du Zeit hast, ...** | Khi/Nếu bạn có thời gian, ... |
| **Ich bleibe zu Hause, weil...** | Tôi ở nhà vì... |
