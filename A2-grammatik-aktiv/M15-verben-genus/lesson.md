## Part 1: Zusammengesetzte Verben — Separable vs Inseparable (Kapitel 47)

### 1.1 Review: Separable Verbs (trennbar)

| Prefix | Example | In sentence |
|---|---|---|
| **an-** | **an**fangen | Ich **fange** um 8 Uhr **an**. |
| **auf-** | **auf**stehen | Ich **stehe** früh **auf**. |
| **ein-** | **ein**kaufen | Ich **kaufe** im Supermarkt **ein**. |
| **mit-** | **mit**kommen | **Kommst** du **mit**? |
| **aus-** | **aus**gehen | Wir **gehen** heute Abend **aus**. |
| **zurück-** | **zurück**kommen | Wann **kommst** du **zurück**? |
| **weg-** | **weg**gehen | Er **geht** jetzt **weg**. |

> 🎯 **Separable prefixes** are stressed: **AN**fangen, **AUF**stehen.

### 1.2 Inseparable Verbs (nicht trennbar)

| Prefix | Example | In sentence |
|---|---|---|
| **be-** | **be**suchen | Ich **besuche** meine Oma. |
| **er-** | **er**zählen | Er **erzählt** eine Geschichte. |
| **ver-** | **ver**stehen | Ich **verstehe** das nicht. |
| **ent-** | **ent**schuldigen | **Entschuldigen** Sie bitte! |
| **ge-** | **ge**fallen | Das **gefällt** mir. |
| **emp-** | **emp**fehlen | Ich **empfehle** das Restaurant. |

> 🎯 **Inseparable prefixes** are unstressed: be**SU**chen, ver**STE**hen. Mnemonic: **BE-ER-VER-ENT-GE-EMP-MISS-ZER** (never separate!)

### 1.3 Participle (Perfekt) Differences

| Type | Partizip II | Example |
|---|---|---|
| Separable | **an**ge**fangen** | Ich habe um 8 **angefangen**. |
| | **ein**ge**kauft** | Ich habe **eingekauft**. |
| Inseparable | **besucht** (no ge-!) | Ich habe meine Oma **besucht**. |
| | **verstanden** (no ge-!) | Ich habe das **verstanden**. |

> 🎯 **Inseparable verbs have NO ge- in Partizip II!**

## Part 2: Genusregeln — Gender Rules (Kapitel 48)

### 2.1 Maskulin (der) — Common Patterns

| Pattern | Examples |
|---|---|
| Male persons | **der** Mann, **der** Vater, **der** Bruder |
| Days, months, seasons | **der** Montag, **der** Januar, **der** Sommer |
| Weather | **der** Regen, **der** Schnee, **der** Wind |
| **-er** (agent) | **der** Lehrer, **der** Fahrer |
| **-ling** | **der** Frühling, **der** Lehrling |
| **-ismus** | **der** Tourismus, **der** Optimismus |

### 2.2 Feminin (die) — Common Patterns

| Pattern | Examples |
|---|---|
| Female persons | **die** Frau, **die** Mutter, **die** Schwester |
| **-ung** | **die** Wohnung, **die** Übung |
| **-heit / -keit** | **die** Freiheit, **die** Möglichkeit |
| **-schaft** | **die** Freundschaft, **die** Mannschaft |
| **-tion / -sion** | **die** Information, **die** Diskussion |
| **-ie** | **die** Energie, **die** Demokratie |
| **-ei** | **die** Bäckerei, **die** Polizei |
| **-in** (female person) | **die** Lehrerin, **die** Ärztin |

### 2.3 Neutrum (das) — Common Patterns

| Pattern | Examples |
|---|---|
| **-chen / -lein** | **das** Mädchen, **das** Brötchen |
| **-um** | **das** Museum, **das** Studium |
| **-ment** | **das** Dokument, **das** Instrument |
| Verb as noun (infinitive) | **das** Essen, **das** Leben, **das** Lernen |
| Metals | **das** Gold, **das** Silber, **das** Eisen |

### 2.4 Quick Cheat Sheet

| Suffix | Gender | Never fails? |
|---|---|---|
| **-ung** | die | ✅ 100% |
| **-chen/-lein** | das | ✅ 100% |
| **-heit/-keit** | die | ✅ 100% |
| **-schaft** | die | ✅ 100% |
| **-tion/-sion** | die | ✅ 100% |
| **-ismus** | der | ✅ 100% |
| **-ment** | das | ✅ 99% |
| **-er** (agent) | der | ⚠️ Most (exceptions: die Butter, das Fenster) |

## 3 · Common Mistakes

| # | ❌ Wrong | ✅ Correct | Why |
|---|---|---|---|
| 1 | Ich habe das nicht **geverstanden**. | Ich habe das nicht **verstanden**. | ver- = inseparable → no ge-! |
| 2 | **die** Mädchen | **das** Mädchen | -chen = always das! |
| 3 | Ich kaufe ein im Supermarkt. | Ich **kaufe** im Supermarkt **ein**. | Prefix goes to END! |
