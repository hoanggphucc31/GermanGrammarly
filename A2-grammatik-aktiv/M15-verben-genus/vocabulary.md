# Module 15 — Vocabulary: Zusammengesetzte Verben & Genusregeln

## Separable Prefixes
| Prefix | Example | 🇻🇳 |
|---|---|---|
| **an-** | anfangen | bắt đầu |
| **auf-** | aufstehen | thức dậy |
| **ein-** | einkaufen | đi mua sắm |
| **mit-** | mitkommen | đi cùng |
| **aus-** | ausgehen | đi ra ngoài |
| **zurück-** | zurückkommen | quay lại |

## Inseparable Prefixes
| Prefix | Example | 🇻🇳 |
|---|---|---|
| **be-** | besuchen | thăm |
| **er-** | erzählen | kể |
| **ver-** | verstehen | hiểu |
| **ent-** | entschuldigen | xin lỗi |
| **ge-** | gefallen | thích |
| **emp-** | empfehlen | giới thiệu |
