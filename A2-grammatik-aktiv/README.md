## Overview

This directory contains the complete A2 grammar curriculum (Kapitel 23-48), organized into 15 modules across 5 phases that follow the textbook spine.

> 💡 Some modules include **expert additions** — supplementary explanations, mnemonics, or examples from experienced German instructors that go beyond the specific chapter content. These are always clearly marked and do not replace the core textbook material.

## Module Architecture

Each module contains 6 files:

| File | Purpose |
|---|---|
| `lesson.md` | Core grammar explanation with examples and dialogues |
| `exercises.md` | Graded practice exercises |
| `answers.md` | Answer key with explanations |
| `vocabulary.md` | Key words grouped by theme |
| `flashcards.md` | Front/back cards for memorization |
| `exam-tips.md` | Goethe A2 exam strategies |
