# Plural Rules Answer Key

## Part A: Identify the Most Likely Pattern

1. `die Blume -> -n / -en`
2. `das Kind -> -er`
3. `der Tisch -> -e`
4. `das Auto -> -s`
5. `der Lehrer -> no ending change`
6. `das Buch -> -er`
7. `die Zeitung -> -n / -en`
8. `das Fenster -> no ending change`
9. `der Stuhl -> umlaut + -e`
10. `die Freundin -> -n / -en`

## Part D: Sort by Pattern

27. `-e`
- `der Tisch`

28. `-n / -en`
- `die Blume`
- `die Freundin`

29. `-er`
- `das Buch`

30. no ending change
- `der Lehrer`
- `das Fenster`

31. `-s`
- `das Auto`

32. umlaut + ending
- `der Stuhl` -> `die Stühle`

## Part E: Fix the Mistake

33. `die Bücher`
Why: `Buch` does not take `-s`. It takes `-er` and umlaut.

34. `die Kinder`
Why: `Kind` does not take `-s`.

35. `die Lehrer`
Why: `Lehrer` usually keeps the same base form in plural.

36. `die Autos`
Why: `Auto` usually takes `-s`.

37. `die Frauenn`
Why: `Frau` takes `-en`.

38. `die Studentenn`
Why: this weak masculine noun normally uses `-en` in plural.

## Part F: Strategy Practice

39. `die Uebung`
- gender: feminine
- likely pattern: `-n / -en`
- plural: `die Uebungen`

40. `der Computer`
- gender: masculine
- likely pattern: no ending change

41. `das Jahr`
- gender: neuter
- likely pattern: `-e`
- plural: `die Jahre`

42. `der Sohn`

- likely pattern: umlaut + `-e`
- plural: `die Söhne`

43. `die Tasche`

- plural: `die Taschen`

44. `das Handy`
