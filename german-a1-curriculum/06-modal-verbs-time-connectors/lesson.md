# Topic 6: Modal Verbs, Imperative, Time Expressions, and Basic Connectors

## Lesson 6.1: Modal Verbs

### Theory

Modal verbs change the meaning of the main verb.

At A1 level, the most useful ones are:

- `koennen` = can
- `muessen` = must / have to
- `wollen` = want
- `moechten` = would like
- `duerfen` = may / be allowed to
- `sollen` = should

### Basic sentence formula

`Subject + modal verb (position 2) + ... + main verb infinitive at the end`

Example:

- `Ich kann Deutsch sprechen.`

### Common forms

| Pronoun | koennen | muessen | wollen |
|---|---|---|---|
| ich | kann | muss | will |
| du | kannst | musst | willst |
| er/sie/es | kann | muss | will |
| wir | koennen | muessen | wollen |
| ihr | koennt | muesst | wollt |
| sie/Sie | koennen | muessen | wollen |

### `moechten`

This form is very common for polite requests.

- `Ich moechte einen Kaffee.`

### Common mistakes

1. Conjugating both verbs
2. Forgetting to place the main verb in the infinitive at the end of the sentence

## Lesson 6.2: Imperative, Time Expressions, and Basic Connectors

### Theory

### Imperative

Some common A1 command forms are:

- `Komm!`
- `Kommen Sie!`
- `Kommt!`

Examples:

- `Lies!`
- `Gehen Sie!`
- `Macht die Tuer zu!`

### Time expressions

- `heute` = today
- `morgen` = tomorrow
- `gestern` = yesterday
- `um 8 Uhr` = at 8 o'clock
- `am Montag` = on Monday
- `im Sommer` = in summer

### Basic connectors

- `und` = and
- `aber` = but
- `oder` = or
- `denn` = because

These connectors usually do not change the basic A1 word order in a simple sentence.

Example:

- `Ich lerne Deutsch, denn ich wohne in Berlin.`

### Time rule summary

| Expression | Use |
|---|---|
| um | clock time |
| am | days, dates |
| im | months, seasons |
