# German A1 Grammar Curriculum

This folder organizes the curriculum into separate lesson, exercise, and answer files so it is easier to study, print, and expand later.

## Structure

- `01-nouns-articles/`
- `02-pronouns-sein-haben/`
- `03-present-tense-separable-verbs/`
- `04-word-order-questions-negation/`
- `05-cases-prepositions/`
- `06-modal-verbs-time-connectors/`
- `practice-test.md`
- `study-plan-21-days.md`
- `memorization-tips.md`

## Recommended Study Order

1. Read `lesson.md` for each topic.
2. Memorize the main formulas and patterns.
3. Complete `exercises.md` without checking the answers.
4. Compare your work with `answers.md`.
5. Mark mistakes and review them later.

## Topic Order

1. Topic 1: Nouns, Articles, Gender, Plural
2. Topic 2: Pronouns, `sein`, `haben`, possessives
3. Topic 3: Present tense verbs, separable verbs
4. Topic 4: Word order, questions, negation
5. Topic 5: Basic cases, prepositions, position and movement
6. Topic 6: Modal verbs, imperative, time, connectors

After finishing the topics, complete `practice-test.md`.
