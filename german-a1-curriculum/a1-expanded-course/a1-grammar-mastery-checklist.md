# A1 Grammar Mastery Checklist

Use this checklist for self-study or classroom review.

Mark each item:

- `Yes`
- `Almost`
- `No`

## 1. Articles and Gender

- I know `der`, `die`, `das`.
- I can learn nouns with the article.
- I can use `ein` and `eine` correctly.

## 2. Plural

- I know that the plural article is `die`.
- I can recognize common plural forms.
- I can use plural nouns in simple sentences.

## 3. Pronouns

- I know `ich, du, er, sie, es, wir, ihr, sie, Sie`.
- I can replace nouns with pronouns.
- I know the difference between `sie` and `Sie`.

## 4. `sein` and `haben`

- I can conjugate `sein`.
- I can conjugate `haben`.
- I can use `sein` for identity and description.
- I can use `haben` for possession.

## 5. Possessives

- I can use `mein`, `dein`, `sein`, `ihr`.
- I can use `unser`, `euer`, `Ihr`.
- I can use `meine` and `meinen` in simple patterns.

## 6. Present Tense Verbs

- I can use regular endings.
- I can use `du` forms correctly.
- I know common irregular forms like `faehrst`, `liest`, `spricht`.

## 7. Separable Verbs

- I know the prefix goes to the end.
- I can use `aufstehen`, `anrufen`, `einkaufen`.
- I can ask simple questions with separable verbs.

## 8. Word Order

- I can build a normal statement.
- I can build a yes/no question.
- I can build a W-question.
- I can use verb-second when time or place comes first.

## 9. Questions

- I can use `wer`, `was`, `wo`, `woher`, `wohin`, `wann`, `wie`.
- I can use `wie alt`, `wie viel`, `wie viele`.
- I can use `du` and `Sie` correctly.

## 10. Negation

- I know when to use `nicht`.
- I know when to use `kein`.
- I can place `nicht` correctly in simple sentences.

## 11. Cases

- I know nominative for the subject.
- I know accusative for the direct object.
- I know dative in basic patterns.

## 12. Articles by Case

- I know `der -> den -> dem`.
- I know `ein -> einen -> einem`.
- I know `kein -> keinen -> keinem`.

## 13. Pronouns by Case

- I know `mich`, `dich`, `ihn`.
- I know `mir`, `dir`, `ihm`, `ihr`, `Ihnen`.
- I can use object pronouns in short sentences.

## 14. Prepositions

- I know common accusative prepositions.
- I know common dative prepositions.
- I can use `mit`, `fuer`, `ohne`, `zu`, `aus`.

## 15. Local Prepositions

- I know `Wo?` takes dative.
- I know `Wohin?` takes accusative.
- I can use `in`, `an`, `auf`, `unter`, `vor`, `hinter`, `neben`, `zwischen`.

## 16. `es gibt`

- I can use `Es gibt` correctly.
- I know it takes the accusative.

## 17. Modal Verbs

- I can use `koennen`, `muessen`, `wollen`.
- I can use `duerfen`, `sollen`, `moechten`.
- I remember the infinitive goes at the end.

## 18. Imperative

- I can form simple commands with `du`.
- I can form simple commands with `ihr`.
- I can form polite commands with `Sie`.

## 19. Time Expressions

- I can use `um` for clock time.
- I can use `am` for days.
- I can use `im` for months and seasons.
- I can use `von ... bis ...`.

## 20. Classroom German

- I can say `Ich verstehe nicht.`
- I can say `Bitte wiederholen Sie.`
- I can ask `Wie sagt man ... auf Deutsch?`
- I can ask `Was bedeutet das?`

## Final Rating

- Mostly `Yes`: ready for strong A1 review
- Many `Almost`: review weak topics again
- Many `No`: go back lesson by lesson

This checklist is strictly A1 level.
