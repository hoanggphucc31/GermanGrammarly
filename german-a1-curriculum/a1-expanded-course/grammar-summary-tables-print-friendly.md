# German A1 Grammar Summary

## Articles

### Definite articles

| Gender | Singular | Plural |
|---|---|---|
| Masculine | der | die |
| Feminine | die | die |
| Neuter | das | die |

### Indefinite articles

| Gender | Singular |
|---|---|
| Masculine | ein |
| Feminine | eine |
| Neuter | ein |

## Plural

| Singular | Plural |
|---|---|
| der Tisch | die Tische |
| die Frau | die Frauen |
| das Kind | die Kinder |
| das Buch | die Buecher |
| der Apfel | die Aepfel |

Plural article: `die`

## Personal Pronouns

| German | English |
|---|---|
| ich | I |
| du | you |
| er | he |
| sie | she |
| es | it |
| wir | we |
| ihr | you all |
| sie | they |
| Sie | you, formal |

## `sein`

| Pronoun | Form |
|---|---|
| ich | bin |
| du | bist |
| er/sie/es | ist |
| wir | sind |
| ihr | seid |
| sie/Sie | sind |

## `haben`

| Pronoun | Form |
|---|---|
| ich | habe |
| du | hast |
| er/sie/es | hat |
| wir | haben |
| ihr | habt |
| sie/Sie | haben |

## Possessive Articles

| Pronoun | Possessive |
|---|---|
| ich | mein |
| du | dein |
| er | sein |
| sie | ihr |
| wir | unser |
| ihr | euer |
| Sie | Ihr |

Examples:

- `mein Bruder`
- `meine Tasche`
- `mein Buch`
- `meinen Bruder`

## Present Tense Endings

| Pronoun | Ending |
|---|---|
| ich | -e |
| du | -st |
| er/sie/es | -t |
| wir | -en |
| ihr | -t |
| sie/Sie | -en |

## Common Irregular Verbs

| Infinitive | du | er/sie/es |
|---|---|---|
| fahren | faehrst | faehrt |
| lesen | liest | liest |
| sprechen | sprichst | spricht |

## Separable Verbs

Pattern:

`Subject + conjugated verb + ... + prefix`

Examples:

- `Ich stehe um 7 Uhr auf.`
- `Er ruft seine Mutter an.`

## Word Order

### Statement

`Subject + verb + ...`

### Yes/No question

`Verb + subject + ... ?`

### W-question

`Question word + verb + subject + ... ?`

### Verb-second with time or place first

| Pattern | Example |
|---|---|
| Time + verb + subject | Heute komme ich. |
| Place + verb + subject | In Berlin wohne ich. |

## Question Words

| German | Meaning |
|---|---|
| wer | who |
| was | what |
| wo | where |
| woher | where from |
| wohin | where to |
| wann | when |
| wie | how |
| warum | why |
| wie alt | how old |
| wie viel | how much |
| wie viele | how many |
| welcher / welche / welches | which |

## `du` and `Sie`

| Informal | Formal |
|---|---|
| Wie heisst du? | Wie heissen Sie? |
| Wo wohnst du? | Wo wohnen Sie? |
| Kommst du aus Italien? | Kommen Sie aus Italien? |

## Negation

| Structure | Example |
|---|---|
| `nicht` + verb idea | Ich komme heute nicht. |
| `nicht` + adjective | Das Buch ist nicht neu. |
| `nicht` + place phrase | Ich wohne nicht in Berlin. |
| `kein` + noun | Ich habe kein Auto. |

| Case | Masculine | Feminine | Neuter | Plural |
|---|---|---|---|---|
| Nominative | der | die | das | die |
| Accusative | den | die | das | die |
| Dative | dem | der | dem | den |

## Indefinite Articles by Case

| Case | Masculine | Feminine | Neuter |
|---|---|---|---|
| Nominative | ein | eine | ein |
| Accusative | einen | eine | ein |
| Dative | einem | einer | einem |

## Dative Verbs

| Verb | Example |
|---|---|
| helfen | Ich helfe dem Mann. |
| danken | Ich danke dir. |

| gefallen | Der Kaffee gefaellt mir. |

## Local Prepositions

| Question | Case | Example |
|---|---|---|
| Wo? | Dative | Das Buch ist auf dem Tisch. |
| Wohin? | Accusative | Ich lege das Buch auf den Tisch. |

Common prepositions:

- `in`
- `an`
- `auf`
- `unter`
- `vor`
- `hinter`
- `neben`
- `zwischen`

## Contractions

| Full form | Short form |
|---|---|
| in dem | im |
| an dem | am |
| zu dem | zum |
| zu der | zur |

## `es gibt`

Pattern:

`Es gibt + accusative noun`

Examples:

- `Es gibt einen Park.`
- `Es gibt eine Schule.`
- `Es gibt ein Cafe.`

## Modal Verbs

| Verb | Meaning |
|---|---|
| koennen | can |
| muessen | must |
| wollen | want |
| duerfen | may |
| sollen | should |
| moechten | would like |

Pattern:

`Subject + modal verb + ... + infinitive`

## Imperative

| Form | Example |
|---|---|
| du | Komm! |
| ihr | Kommt! |
| Sie | Kommen Sie! |

## Time Expressions

| Structure | Example |
|---|---|
| um + time | um 8 Uhr |
| am + day | am Montag |
| am + part of day | am Morgen |
| im + month / season | im Juli, im Sommer |
| von ... bis ... | von Montag bis Freitag |
| am + date | am 5. Mai |

## Connectors

| Connector | Meaning |
|---|---|

| aber | but |
| oder | or |
