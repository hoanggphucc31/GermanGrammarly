# Lessons 8-15

## Lesson 8: Negation with `nicht` and `kein`

### Goal

You learn how to say `not` and `no` in simple German sentences.

### Theory

Use `nicht` to negate:

- a verb
- an adjective
- an adverb
- a whole idea

Use `kein` to negate nouns.

Examples:

- `Ich komme nicht.`
- `Das ist nicht teuer.`
- `Ich habe kein Auto.`
- `Sie hat keine Zeit.`

### Common mistakes

1. Saying `nicht Auto`
2. Using `kein` with adjectives
3. Placing `nicht` too early

### Vocabulary

| Word | Meaning |
|---|---|
| nicht | not |
| kein | no, not any |
| keine | no, not any |
| keinen | no, not any |
| teuer | expensive |
| billig | cheap |
| Zeit | time |
| Auto | car |
| Brot | bread |
| Kaffee | coffee |
| Katze | cat |
| Hund | dog |
| heute | today |
| hier | here |
| da | there |
| muede | tired |
| neu | new |
| alt | old |
| kommen | to come |
| haben | to have |

### Key Vocabulary Sentences

- `Ich habe kein Brot.`
- `Er ist nicht hier.`
- `Das ist nicht billig.`
- `Wir haben keine Zeit.`
- `Sie kommt heute nicht.`

### Self-Check

This lesson is strictly A1 level.

## Lesson 9: Nominative and Accusative

### Goal

You learn the difference between the subject and the direct object.

### Theory

Nominative = subject

Accusative = direct object

Important change:

- `der -> den`
- `ein -> einen`

Examples:

- `Der Mann kauft einen Apfel.`
- `Ich sehe den Lehrer.`

### Common mistakes

1. Using `der` after `sehen`
2. Forgetting `einen`
3. Thinking feminine and neuter always change the same way as masculine

### Vocabulary

| Word | Meaning |
|---|---|
| sehen | to see |
| kaufen | to buy |
| haben | to have |
| brauchen | to need |
| nehmen | to take |
| der Mann | the man |
| der Lehrer | the teacher |
| der Apfel | the apple |
| der Stuhl | the chair |
| der Hund | the dog |
| die Tasche | the bag |
| die Frau | the woman |
| die Banane | the banana |
| das Buch | the book |
| das Auto | the car |
| das Brot | the bread |
| einen | a, masculine acc. |
| den | the, masculine acc. |
| ein | a, neuter |
| eine | a, feminine |

### Key Vocabulary Sentences

- `Ich sehe den Hund.`
- `Sie kauft eine Banane.`
- `Er nimmt den Stuhl.`
- `Wir brauchen ein Auto.`
- `Du hast einen Bruder.`

### Self-Check

This lesson is strictly A1 level.

## Lesson 10: Dative and Common Prepositions

## Lesson 13: Position and Place Articles

### Goal

You learn how to answer `Wo?` and `Wohin?` with very common place prepositions.

### Theory

`Wo?` uses dative.

`Wohin?` uses accusative.

Common place prepositions:

- `in`
- `an`
- `auf`
- `unter`
- `vor`
- `hinter`
- `neben`
- `zwischen`

Examples:

- `Das Buch ist auf dem Tisch.`
- `Ich lege das Buch auf den Tisch.`

### Common mistakes

1. using dative for movement
2. using accusative for location
3. mixing up `im` and `in die`

### Vocabulary

| auf | on |
| unter | under |

### Key Vocabulary Sentences

## Lesson 14: Modal Verbs

### Goal

You learn simple modal verbs in daily situations.

### Theory

Pattern:

`Subject + modal verb + ... + infinitive`

Examples:

- `Ich kann Deutsch sprechen.`
- `Du musst heute arbeiten.`
- `Wir wollen Wasser kaufen.`

Common modal verbs:

- `koennen`
- `muessen`
- `wollen`
- `duerfen`
- `sollen`
- `moechten`

### Common mistakes

1. Conjugating the second verb
2. forgetting the infinitive at the end
3. using long complex sentences

### Vocabulary

| duerfen | may |

## Lesson 15: Imperative, Time Expressions, and Basic Connectors

### Goal

You learn simple commands, basic time phrases, and easy connectors.

### Theory

Imperative examples:

- `Komm!`
- `Kommt!`
- `Kommen Sie!`

Time expressions:

- `um 8 Uhr`
- `am Montag`
- `im Sommer`

Basic connectors:

- `und`
- `aber`
- `oder`

### Common mistakes

1. using the wrong time word
2. mixing `um`, `am`, and `im`
3. making command forms too long

### Key Vocabulary Sentences
