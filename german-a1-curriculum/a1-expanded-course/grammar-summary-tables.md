# German A1 Grammar Summary Tables

This file gives one compact overview of the main A1 grammar structures.

## 1. Definite Articles

| Gender | Singular | Plural |
|---|---|---|
| Masculine | der | die |
| Feminine | die | die |
| Neuter | das | die |

## 2. Indefinite Articles

| Gender | Singular |
|---|---|
| Masculine | ein |
| Feminine | eine |
| Neuter | ein |

## 3. Plural Basics

| Singular | Plural |
|---|---|
| der Tisch | die Tische |
| die Frau | die Frauen |
| das Kind | die Kinder |
| das Buch | die Buecher |
| der Apfel | die Aepfel |

Plural article: `die`

## 4. Personal Pronouns

| German | English |

| ich | I |

| er | he |
| sie | she |
| es | it |
| wir | we |

| Pronoun | Form |
|---|---|

| Pronoun | Form |
|---|---|
| ich | habe |
| du | hast |
| er/sie/es | hat |
| wir | haben |
| ihr | habt |
| sie/Sie | haben |

## 7. Possessive Articles

| Pronoun | Possessive |
|---|---|
| ich | mein |
| du | dein |
| er | sein |
| sie | ihr |
| wir | unser |
| ihr | euer |
| Sie | Ihr |

Examples:

- `mein Bruder`
- `meine Tasche`
- `mein Buch`
- `meinen Bruder`

## 8. Present Tense Endings

| Pronoun | Ending |
|---|---|
| ich | -e |
| du | -st |
| er/sie/es | -t |
| wir | -en |
| ihr | -t |
| sie/Sie | -en |

## 9. Common Irregular Verb Changes

| Infinitive | du | er/sie/es |
|---|---|---|
| fahren | faehrst | faehrt |
| lesen | liest | liest |
| sprechen | sprichst | spricht |

## 10. Separable Verbs

Pattern:

`Subject + conjugated verb + ... + prefix`

Examples:

- `Ich stehe um 7 Uhr auf.`
- `Er ruft seine Mutter an.`

## 11. Basic Word Order

Statement:

`Subject + verb + ...`

Question:

`Verb + subject + ... ?`

W-question:

`Question word + verb + subject + ... ?`

## 12. Verb-Second with Time or Place First

| Pattern | Example |
|---|---|
| Time + verb + subject | Heute komme ich. |
| Place + verb + subject | In Berlin wohne ich. |

## 13. Question Words

| German | Meaning |
|---|---|
| wer | who |
| was | what |
| wo | where |
| woher | where from |
| wohin | where to |
| wann | when |
| wie | how |
| warum | why |
| wie alt | how old |
| wie viel | how much |
| wie viele | how many |
| welcher / welche / welches | which |

## 14. `du` and `Sie`

| Informal | Formal |
|---|---|
| Wie heisst du? | Wie heissen Sie? |
| Wo wohnst du? | Wo wohnen Sie? |
| Kommst du aus Italien? | Kommen Sie aus Italien? |

## 15. Negation

| Structure | Example |
|---|---|
| nicht + verb idea | Ich komme heute nicht. |
| nicht + adjective | Das Buch ist nicht neu. |
| nicht + place phrase | Ich wohne nicht in Berlin. |
| kein + noun | Ich habe kein Auto. |

|---|---|---|---|---|
| Nominative | der | die | das | die |
| Accusative | den | die | das | die |
| Dative | dem | der | dem | den |

## 17. Indefinite Articles by Case

| Dative | einem | einer | einem |

## 22. Common Dative Verbs

| Verb | Example |
|---|---|
| helfen | Ich helfe dem Mann. |
| danken | Ich danke dir. |
| gehoeren | Das Buch gehoert der Frau. |

## 23. Local Prepositions: `wo` and `wohin`

| Question | Case | Example |
|---|---|---|
| Wo? | Dative | Das Buch ist auf dem Tisch. |
| Wohin? | Accusative | Ich lege das Buch auf den Tisch. |

Common prepositions:

- `in`
- `an`
- `auf`
- `unter`
- `vor`
- `hinter`
- `neben`
- `zwischen`

## 24. Contractions

| Full form | Short form |
|---|---|
| in dem | im |
| an dem | am |
| zu dem | zum |
| zu der | zur |

## 25. `es gibt`

Pattern:

`Es gibt + accusative noun`

Examples:

- `Es gibt einen Park.`
- `Es gibt eine Schule.`
- `Es gibt ein Cafe.`

## 26. Modal Verbs

| Verb | Meaning |
|---|---|
| koennen | can |
| muessen | must |
| wollen | want |
| duerfen | may |
| sollen | should |
| moechten | would like |

Pattern:

`Subject + modal verb + ... + infinitive`

Example:

- `Ich kann Deutsch sprechen.`

## 27. Imperative

| Form | Example |
|---|---|
| du | Komm! |
| ihr | Kommt! |
| Sie | Kommen Sie! |

## 28. Time Expressions

| Structure | Example |
|---|---|
| um + time | um 8 Uhr |

| am + part of day | am Morgen |
| im + month / season | im Juli, im Sommer |
| von ... bis ... | von Montag bis Freitag |
| am + date | am 5. Mai |
