# Lessons 16-23

## Lesson 16: Verb-Second with Time and Place First

### Goal

You learn how to keep the verb in position 2 when a time phrase or place phrase comes first.

### Theory

In German, the conjugated verb stays in position 2.

Normal order:

- `Ich komme heute.`
- `Ich wohne in Berlin.`

Time first:

- `Heute komme ich.`
- `Am Montag lerne ich Deutsch.`

Place first:

- `In Berlin wohne ich.`
- `In der Schule lerne ich Deutsch.`

### Formula

`Time / Place + verb + subject + ...`

### Common mistakes

1. `Heute ich komme.`
2. `In Berlin ich wohne.`
3. forgetting the verb-second rule

### Vocabulary

| Word | Meaning |
|---|---|
| heute | today |
| morgen | tomorrow |
| am Montag | on Monday |
| am Abend | in the evening |
| in Berlin | in Berlin |
| in der Schule | at school |
| zu Hause | at home |
| jetzt | now |
| spaeter | later |
| dort | there |

### Self-Check

This lesson is strictly A1 level.

## Lesson 17: Accusative Prepositions

### Goal

You learn the most common A1 prepositions that take the accusative.

### Theory

These common prepositions take the accusative:

- `fuer`
- `ohne`
- `durch`
- `gegen`
- `um`

Examples:

- `Das Geschenk ist fuer meinen Freund.`
- `Ich gehe ohne Kaffee.`
- `Wir gehen durch den Park.`
- `Wir treffen uns gegen 8 Uhr.`
- `Der Kurs ist um 9 Uhr.`

### Common mistakes

1. using nominative after the preposition
2. mixing `mit` and `fuer`
3. forgetting `den / einen` with masculine nouns

### Vocabulary

| Word | Meaning |
|---|---|
| fuer | for |
| ohne | without |
| durch | through |
| gegen | around, against |
| um | at, around |
| Park | park |
| Freund | friend |
| Kaffee | coffee |
| Uhr | o'clock |
| Geschenk | gift |

### Self-Check

This lesson is strictly A1 level.

## Lesson 18: Article Overview by Case and `kein`

### Goal

You learn the article system for nominative, accusative, and dative in one clear table.

### Theory

#### Definite articles

| Case | Masculine | Feminine | Neuter | Plural |
|---|---|---|---|---|
| Nominative | der | die | das | die |
| Accusative | den | die | das | die |
| Dative | dem | der | dem | den |

#### Indefinite articles

| Case | Masculine | Feminine | Neuter |
|---|---|---|---|
| Nominative | ein | eine | ein |
| Accusative | einen | eine | ein |
| Dative | einem | einer | einem |

#### `kein`

| Case | Masculine | Feminine | Neuter | Plural |
|---|---|---|---|---|
| Nominative | kein | keine | kein | keine |
| Accusative | keinen | keine | kein | keine |
| Dative | keinem | keiner | keinem | keinen |

### Key idea

At A1 level, the most important changes are:

- `der -> den -> dem`
- `ein -> einen -> einem`
- `kein -> keinen -> keinem`

### Self-Check

This lesson is strictly A1 level.

## Lesson 19: Pronoun and Possessive Overview

### Goal

You learn a simple overview of nominative, accusative, dative pronouns, and basic possessive forms.

### Theory

#### Personal pronouns

| Nominative | Accusative | Dative |
|---|---|---|
| ich | mich | mir |
| du | dich | dir |
| er | ihn | ihm |
| sie | sie | ihr |
| es | es | ihm |
| wir | uns | uns |
| ihr | euch | euch |
| sie | sie | ihnen |
| Sie | Sie | Ihnen |

#### Basic possessive pattern

| Base form | Example |
|---|---|
| mein | mein Bruder |
| meine | meine Tasche |
| mein | mein Buch |
| meinen | ich sehe meinen Bruder |

### Common mistakes

1. `ich sehe er`
2. `ich helfe dich`
3. `mein Tasche`

## Lesson 20: More Question Forms and `du` / `Sie`

### Goal

You learn more useful A1 question forms and the difference between informal and formal address.

### Theory

Useful question forms:

- `Wie alt bist du?`
- `Wie viel kostet das?`
- `Wie viele Kinder hast du?`
- `Welcher Bus faehrt nach Bonn?`
- `Warum lernst du Deutsch?`

Informal:

- `Wie heisst du?`
- `Wo wohnst du?`

Formal:

- `Wie heissen Sie?`
- `Wo wohnen Sie?`

### Common mistakes

1. mixing `du` and `Sie`
2. using `bist` with `Sie`
3. using singular after `wie viele`

### Self-Check

This lesson is strictly A1 level.

## Lesson 21: `es gibt`

### Goal

You learn how to say that something exists.

### Theory

`es gibt` means `there is` or `there are`.

Pattern:

`Es gibt + accusative noun`

Examples:

- `Es gibt einen Park.`
- `Es gibt eine Schule.`
- `Es gibt ein Cafe.`
- `Es gibt viele Autos.`

### Common mistakes

1. using nominative after `es gibt`
2. forgetting `einen` with masculine nouns
3. writing `Es sind` instead of `Es gibt` when the meaning is existence

### Vocabulary

| Word | Meaning |
|---|---|
| es gibt | there is, there are |
| Park | park |
| Schule | school |
| Cafe | cafe |
| Supermarkt | supermarket |
| Bahnhof | train station |
| Krankenhaus | hospital |
| Wohnung | apartment |
| Bus | bus |
| Auto | car |

### Self-Check

This lesson is strictly A1 level.

## Lesson 22: Position of `nicht`

### Goal

You learn the most common A1 positions of `nicht` in a sentence.

### Theory

`nicht` often comes:

1. at the end of the clause to negate the action
- `Ich komme heute nicht.`

2. before an adjective
- `Das Buch ist nicht neu.`

3. before a place phrase when the place is negated
- `Ich wohne nicht in Berlin.`

4. before a specific word you want to negate
- `Nicht ich, sondern Paul.`

### Common mistakes

1. `Ich nicht komme heute.`
2. `Das ist kein neu.`
3. `Ich wohne in Berlin nicht.` in simple A1 usage

### Self-Check

This lesson is strictly A1 level.

## Lesson 23: Time, Dates, and Classroom German

### Goal

You learn more useful A1 time expressions and basic classroom phrases.

### Theory

Useful time patterns:

- `am Montag`
- `am Morgen`
- `am Abend`
- `im Juli`
- `im Sommer`
- `von Montag bis Freitag`
- `am 5. Mai`

Useful classroom German:

- `Ich verstehe nicht.`
- `Bitte wiederholen Sie.`
- `Wie sagt man ... auf Deutsch?`
- `Was bedeutet das?`
- `Noch einmal, bitte.`

### Common mistakes

1. mixing `am` and `im`
2. saying very long English-style questions
3. forgetting polite forms in class

### Vocabulary

| Word | Meaning |
|---|---|
| am Morgen | in the morning |
| am Abend | in the evening |
| im Juli | in July |
| von ... bis ... | from ... to ... |
| verstehen | to understand |
| wiederholen | to repeat |
| bedeuten | to mean |
| noch einmal | once again |
| bitte | please |
| auf Deutsch | in German |

### Self-Check

This lesson is strictly A1 level.
