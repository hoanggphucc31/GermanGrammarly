# A1 Exercise Workbook

This workbook reorganizes the expanded exercises into a more professional teaching flow.

## Workbook Principles

Each lesson follows the same structure:

1. Lesson focus
2. Learning targets
3. Exercise order
4. Suggested timing
5. Answer routing

## Standard Exercise Flow

Every lesson should be completed in this order:

1. Vocabulary Warm-Up
Questions `1-10`

2. Core Form Practice
Questions `11-25`

3. Sentence Control Practice
Questions `26-40`

4. Practical Communication Practice
Questions `41-55`

5. Review Check
Questions `56-70`
