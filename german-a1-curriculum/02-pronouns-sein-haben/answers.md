# Topic 2 Answer Key

1. `Sie`  
Why: Anna = she.

2. `Sie`  
Why: Paul und Tim = they.

3. `Sie`  
Why: formal you.

4. `Wir`  
Why: Ich und Leon = we.

5. `Es`  
Why: `das Buch` = it.

6. `bin`  
Why: `ich bin`.

7. `bist`  
Why: `du bist`.

8. `ist`  
Why: `er ist`.

9. `sind`  
Why: `wir sind`.

10. `seid`  
Why: `ihr seid`.

11. `sind`  
Why: `sie sind`.

12. `Sind`  
Why: formal question with `Sie`.

13. `habe`  
Why: `ich habe`.

14. `hast`  
Why: `du hast`.

15. `hat`  
Why: `er hat`.

16. `haben`  
Why: `wir haben`.

17. `habt`  
Why: `ihr habt`.

18. `hat`  
Why: `sie` = she, so `hat`.

19. `haben`  
Why: formal `Sie haben`.

20. `mein`  
Why: speaker = ich.

21. `dein`  
Why: speaker addresses `du`.

22. `sein`  
Why: `er -> sein`.

23. `ihre`  
Why: feminine noun `Tasche`.

24. `unsere`  
Why: feminine noun `Wohnung`.

25. `Ihr`  
Why: formal `Sie -> Ihr`.

26. `b. bin`  
Why: `aus ... sein`, not `haben`.

27. `a. haben`  
Why: possession uses `haben`.

28. `b. bist`  
Why: `du bist`.

29. `c. Sie`  
Why: Anna = she.

30. `b. sind`  
Why: `Sind Sie Lehrer?`
