# Learning Roadmap Based on Grammatik aktiv A1-B1

## Purpose of this file
This file summarizes the main content of `746948531-Grammatik-Aktiv-A1-B1.pdf` and turns it into a practical learning/teaching roadmap that can be used as a framework for building a lesson program.

The book follows a clear progression from A1 to B1 and is especially strong in:
- core grammar and sentence usage
- pattern practice through exercises
- linking grammar forms with communicative situations
- grouping topics in a way that supports structured teaching

## How the book is structured
The book contains 65 main grammar units, grouped around these larger areas:
- verbs and basic sentence building
- questions and word order
- nouns, articles, negation, Akkusativ/Dativ
- past tenses: Perfekt, Prateritum, Plusquamperfekt
- prepositions and adverbials of time, place, and direction
- adjectives, comparison, and superlative
- subordinate clauses, conjunctions, sentence linking
- passive, Futur I, Konjunktiv II, Genitiv, n-declension

## Content overview by level

### Stage 1: Core A1
This stage focuses on building simple sentences, conjugating verbs, asking questions, and controlling basic word order.

Main topics in the book:
- Units 1-8: personal pronouns, present tense conjugation, `sein`, `haben`, special verbs, separable verbs, modal verbs, imperative
- Units 9-12: wh-questions, yes/no questions, sentence word order, verb position
- Units 13-15: plural forms, definite/indefinite articles, negation with `kein`, `nicht`, `nie`
- Units 16-22: Akkusativ, Dativ, possessive articles, personal pronouns in Akkusativ/Dativ, verbs that take Akkusativ and Dativ

Suggested learning outcomes:
- introduce oneself, ask and answer basic questions, talk about daily routines
- use basic word order in statements, questions, and commands
- recognize and use Nominativ, Akkusativ, and Dativ at a basic level

Teaching suggestions:
- Teach in clusters such as `pronoun + verb + sentence frame + question`
- Each lesson should include one communicative dialogue model and one short sentence-writing task
- Teach pronunciation and sentence reading together with grammar, not separately

### Stage 2: Foundation A2
This stage expands the case system, past tense usage, prepositions, adjectives, and sentence linking.

Main topics in the book:
- Units 23-29: Prateritum of `sein/haben/modalverben`, Perfekt with `haben/sein`, Partizip II, tense usage in the past, reflexive verbs
- Units 30-35: time prepositions, prepositions with Dativ, prepositions with Akkusativ, Wechselpraepositionen, local prepositions
- Units 36-39: adjective endings, comparative, superlative
- Units 40-44: conjunctions `und/aber/oder/denn`, linking adverbs `deshalb/sonst/dann/danach`, subordinate clauses with `weil/dass/wenn`, adverbs of position/direction, particles such as `denn`, `doch`, `mal`
- Units 45-48: compounds, word formation, compound/separable structures, gender patterns

Suggested learning outcomes:
- talk about past events using Perfekt and key Prateritum forms
- use prepositions for time, place, movement, and direction
- describe people and objects with adjectives and comparisons
- link 2-3 ideas into a short, logical spoken or written stretch

Teaching suggestions:
- Teach Perfekt in 3 layers: auxiliary, past participle, final position
- Teach prepositions in meaning pairs such as `wo?` and `wohin?`, not as isolated lists
- Teach `weil/dass/wenn` with real communicative situations: reasons, opinions, conditions

### Stage 3: Core B1
This stage focuses on complex sentences, advanced tense control, passive, assumptions, hypotheticals, and more academic structures.

Main topics in the book:
- Units 49-50: expanded Prateritum, Plusquamperfekt
- Units 51-54: reflexive pronouns in Dativ, advanced separable/non-separable verbs, verb + preposition structures, pronominal adverbs and pronouns
- Units 55-56: Konjunktiv II forms and uses for hypotheticals, politeness, suggestions, and advice
- Units 57-60: Passiv Part 1-2, Futur I, functions of `werden`
- Units 61-64: `lassen`, position/direction verbs (`sitzen/setzen`, `stehen/stellen`, `liegen/legen`, `haengen`), Genitiv, n-declension
- Unit 65: adjectives used as nouns for people

Suggested learning outcomes:
- narrate and describe events with a clear time sequence
- use more complex sentence structures and subordinate clauses
- understand and produce basic passive structures in informative texts
- express hypotheticals, wishes, and advice with Konjunktiv II
- read and write short B1 texts on everyday life, work, services, and media

Teaching suggestions:
- Teach `werden` in its 3 separate roles: future, passive, becoming
- Teach Konjunktiv II through communicative function first, not mainly as a form table
- Teach passive only after learners are confident with Akkusativ, Partizip II, and final verb position

## Roadmap for building a teaching program

### Phase 1: A1 Foundation
Suggested duration: 6-8 weeks

Module 1. Pronouns and basic verb conjugation
- Book units: 1-4
- Goal: present tense conjugation, use of `sein/haben`, recognition of vowel-changing verbs
- Output: learners can build self-introduction sentences and ask for personal information

Module 2. Modal verbs, separable verbs, imperative
- Book units: 5-8
- Goal: express ability, obligation, intention, and commands
- Output: learners can talk about routine, plans, and simple requests

Module 3. Questions and basic word order
- Book units: 9-12
- Goal: ask for information, form yes/no questions, place the verb correctly
- Output: learners can create short dialogues of 6-8 turns

Module 4. Nouns, articles, negation
- Book units: 13-15
- Goal: plural forms, article usage, `kein/nicht/nie`
- Output: learners can describe objects, people, quantity, possession, and negation

Module 5. Basic case system
- Book units: 16-22
- Goal: Akkusativ, Dativ, possessive articles, verbs with case patterns
- Output: learners can express who does what to whom, buys something for someone, gives something to someone

### Phase 2: A2 Consolidation
Suggested duration: 8-10 weeks

Module 6. Basic past tense system
- Book units: 23-29
- Goal: Perfekt, Partizip II, `haben/sein`, key Prateritum forms
- Output: learners can talk about yesterday, a trip, and a personal experience

Module 7. Preposition system
- Book units: 30-35
- Goal: time prepositions, Dativ/Akkusativ prepositions, Wechselpraepositionen, local structures
- Output: learners can describe schedules, locations, directions, and routes

Module 8. Adjectives and description
- Book units: 36-39
- Goal: basic adjective endings, comparative, superlative
- Output: learners can compare people, objects, cities, and services

Module 9. Sentence linking and subordinate clauses
- Book units: 40-44
- Goal: conjunctions, `weil/dass/wenn`, linking adverbs
- Output: learners can speak or write a 6-8 sentence paragraph with reasons, conditions, and results

Module 10. Vocabulary and structural expansion
- Book units: 45-48
- Goal: compounds, word formation, compound verb patterns, gender recognition
- Output: learners can understand texts better and guess the meaning of new words from context

### Phase 3: B1 Application
Suggested duration: 8-10 weeks

Module 11. Advanced past tense system
- Book units: 49-50
- Goal: expanded Prateritum, Plusquamperfekt
- Output: learners can narrate events with before/after sequence and cause/effect relationships

Module 12. Advanced verb structures
- Book units: 51-54, 61-62
- Goal: reflexive Dativ, verb + preposition, `lassen`, position/direction verb pairs
- Output: learners can express more complex actions and describe real-life situations more precisely

Module 13. Konjunktiv II
- Book units: 55-56
- Goal: hypotheticals, wishes, polite requests, advice, suggestions
- Output: learners can discuss hypothetical situations and give advice

Module 14. Passive, Futur I, `werden`
- Book units: 57-60
- Goal: present and past passive, future meaning, prediction, the functions of `werden`
- Output: learners can read and write short informational texts, notices, processes, and simple news-style texts

Module 15. Advanced noun structures
- Book units: 63-65
- Goal: Genitiv, n-declension, adjectival nouns for people
- Output: learners can understand B1-level informational and descriptive structures better

## How to turn this roadmap into a teaching program

### 1. If you want a full course structure
Use the 15 modules above, with 2-4 lessons per module:
- 1 lesson for model patterns and rule explanation
- 1 lesson for controlled practice
- 1 lesson for speaking/writing application
- 1 review and mini-test lesson if needed

### 2. If you want a communication-based course
You can regroup the content into 6 larger teaching blocks:
- introducing yourself and asking basic questions
- talking about routines and plans
- shopping, transport, appointments, asking for directions
- narrating past events
- expressing reasons, conditions, and opinions
- reading and writing B1 texts with more complex structures

### 3. If you want exam-oriented staging
You can divide it clearly into 3 tracks:
- A1: Units 1-22
- A2: Units 23-48
- B1: Units 49-65

## Recommended priority order for lesson design
If you want an efficient progression, prioritize in this order:
1. Verbs and sentence word order
2. Questions and negation
3. Case system and articles
4. Perfekt and past reference
5. Prepositions and place/direction structures
6. Subordinate clauses and sentence linking
7. Adjectives and comparison
8. Passive, Konjunktiv II, Futur, Genitiv

## Strengths of the book for teaching
- Short lessons focused on one grammar point at a time
- Many sentence-building exercises that work well for guided speaking
- Partner pages that are useful for pair work and small group work
- A logical progression from easier to harder topics, which supports syllabus design

## What should be added for a complete course
The book is very strong in grammar, but to build a complete learning program you should add:
- topic-based vocabulary
- listening and speaking tasks based on real situations
- short graded reading texts
- short writing tasks in exam-style formats
- mini speaking tasks in each module

## Suggested end-of-stage outcomes

### End of A1
Learners can:
- introduce themselves
- ask and answer basic personal questions
- describe daily routine
- use present tense, modal verbs, and basic Akkusativ/Dativ structures

### End of A2
Learners can:
- talk about past events with reasonable control of Perfekt
- use common prepositions
- express opinions, reasons, and simple conditions in short form
- write short linked paragraphs

### End of B1
Learners can:
- present familiar topics in an organized way
- use complex sentences, passive, and basic Konjunktiv II
- read and write short informational or narrative texts
