# Module 10 — Flashcards: Possessivartikel, welcher/dieser & Pronomen

---

## Possessives

| Front | Back |
|---|---|
| my (masc Nom) | **mein** |
| my (fem Nom) | **meine** |
| my (masc Akk) | **meinen** |
| my (masc Dat) | **meinem** |
| my (fem Dat) | **meiner** |
| euer + ending? | Drop inner -e-: **eure** |

---

## welcher / dieser

| Front | Back |
|---|---|
| Which coffee? (Akk m) | **Welchen** Kaffee? |
| This coffee. (Akk m) | **Diesen** Kaffee. |
| Which book? (Nom n) | **Welches** Buch? |
| This book. (Nom n) | **Dieses** Buch. |
| With which bus? (Dat m) | Mit **welchem** Bus? |
| With this bus. (Dat m) | Mit **diesem** Bus. |

---
