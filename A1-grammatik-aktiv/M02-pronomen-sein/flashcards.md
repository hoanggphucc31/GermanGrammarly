# Module 02 — Flashcards: Konjugation Präsens

---

## Ending Pattern

| Front | Back |
|---|---|
| ich + ending | **-e** |
| du + ending | **-st** |
| er/sie/es + ending | **-t** |
| wir + ending | **-en** |
| ihr + ending | **-t** |
| sie/Sie + ending | **-en** |

---

## Model Verb: kommen

| Front | Back |
|---|---|
| ich + kommen | ich **komme** |
| du + kommen | du **kommst** |
| er + kommen | er **kommt** |
| wir + kommen | wir **kommen** |
| ihr + kommen | ihr **kommt** |
| Sie + kommen | Sie **kommen** |

---

## Special Cases

| Front | Back |
|---|---|
| du + arbeiten | du **arbeitest** (buffer -e-!) |
| er + arbeiten | er **arbeitet** |
| du + heißen | du **heißt** (NOT heißst!) |
| du + antworten | du **antwortest** |
| er + öffnen | er **öffnet** |

---

## Common Mistakes

| Front (❌) | Back (✅) |
|---|---|
| Er **kommen** aus Berlin. | Er **kommt** (er = -t) |
| Du **arbeitst** | Du **arbeitest** (buffer -e-) |
| Du **heißst** | Du **heißt** (ß absorbs s) |
| Ich wohne **Berlin**. | Ich wohne **in** Berlin. |
