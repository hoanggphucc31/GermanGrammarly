# Module 04 — Flashcards: Modalverben

---

## Modal Conjugation (ich = er!)

| Front | Back |
|---|---|
| ich + können | **ich kann** |
| er + können | **er kann** (same as ich!) |
| du + müssen | **du musst** |
| ich + dürfen | **ich darf** |
| du + wollen | **du willst** |
| ich + sollen | **ich soll** |
| ich + möchten | **ich möchte** |

---

## Modal Meanings

| Front | Back |
|---|---|
| ability: I **can** swim. | Ich **kann** schwimmen. |
| permission: **May** I...? | **Darf** ich...? |
| obligation: I **must** go. | Ich **muss** gehen. |
| wish (polite): I **would like**... | Ich **möchte**... |
| wish (strong): I **want**... | Ich **will**... |
| advice: You **should**... | Du **sollst**... |

---

## Contrast Pairs

| Front | Back |
|---|---|
| können vs dürfen? | können = ability, dürfen = permission |
| müssen vs sollen? | müssen = obligation, sollen = advice |
| wollen vs möchten? | wollen = strong, möchten = polite |
| "must not" in German? | **darf nicht** (NOT muss nicht!) |

---

## Sentence Frame

| Front | Back |
|---|---|
| Modal position? | Position **2** (conjugated) |
| Main verb position? | **End** of sentence (infinitive) |
| Ich / Deutsch / muss / lernen | **Ich muss Deutsch lernen.** |
