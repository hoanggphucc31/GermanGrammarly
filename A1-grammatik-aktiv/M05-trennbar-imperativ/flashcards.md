# Module 05 — Flashcards: Trennbare Verben & Imperativ

---

## Separable Verbs — Split!

| Front | Back |
|---|---|
| aufstehen → ich... | Ich **stehe** um 7 Uhr **auf**. |
| einkaufen → wir... | Wir **kaufen** im Supermarkt **ein**. |
| anrufen → du...? | **Rufst** du Maria **an**? |
| fernsehen → er... | Er **sieht** abends **fern**. |
| anfangen → der Kurs... | Der Kurs **fängt** um 9 **an**. |

---

## With Modal → Stays Together!

| Front | Back |
|---|---|
| aufstehen + müssen | Ich **muss** um 6 Uhr **aufstehen**. |
| einkaufen + möchten | Ich **möchte** heute **einkaufen**. |
| anrufen + können | **Kannst** du Maria **anrufen**? |

---

## Imperative — du

| Front | Back |
|---|---|
| kommen → du | **Komm!** |
| sprechen → du | **Sprich!** (e→i!) |
| nehmen → du | **Nimm!** (e→i!) |
| lesen → du | **Lies!** (e→ie!) |
| helfen → du | **Hilf!** (e→i!) |
| fahren → du | **Fahr!** (NO Umlaut!) |
| sein → du | **Sei!** |

---

## Imperative — Separable

| Front | Back |
|---|---|
| aufstehen → du | **Steh auf!** |
| zumachen → du | **Mach zu!** |
| mitkommen → ihr | **Kommt mit!** |
| anrufen → Sie | **Rufen Sie an!** |
