# Module 11 — Flashcards: Verben mit Akkusativ und Dativ

---

## Word Order Rule

| Front | Back |
|---|---|
| Rule for Two Objects: Person & Thing? | **Person (Dativ) BEFORE Thing (Akkusativ)** |
| Order: Ich gebe (das Buch) (dem Mann) | Ich gebe **dem Mann** **das Buch**. |

---

## Dativ-Only Verbs

| Front | Back |
|---|---|
| helfen (to help) → Case? | **Dativ** |
| danken (to thank) → Case? | **Dativ** |
| gehören (to belong to) → Case? | **Dativ** |
| gefallen (to please/like) → Case? | **Dativ** |
| antworten (to answer) → Case? | **Dativ** |

---

## Dat+Akk Verbs

| Front | Back |
|---|---|
| geben (to give) → Case? | **Dativ (Person) + Akkusativ (Thing)** |
| zeigen (to show) → Case? | **Dativ (Person) + Akkusativ (Thing)** |
| schenken (to gift) → Case? | **Dativ (Person) + Akkusativ (Thing)** |

---

## Pronoun Replacement (Dativ)

| Front | Back |
|---|---|
| der Mann (Dat) → Pronoun? | **ihm** |
| die Frau (Dat) → Pronoun? | **ihr** |
| das Kind (Dat) → Pronoun? | **ihm** |
| die Kinder (Dat) → Pronoun? | **ihnen** |
| du (Dat) → Pronoun? | **dir** |
| ich (Dat) → Pronoun? | **mir** |
