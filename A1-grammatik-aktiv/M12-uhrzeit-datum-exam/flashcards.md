## Final A1 Grammar Check

| Front | Back |
|---|---|
| Which case? (Subject) | **Nominativ** |
| Which case? (Direct Object, "Thing") | **Akkusativ** |
| Which case? (Indirect Object, "Person") | **Dativ** |
| Akkusativ article change? | ONLY **der → den** (ein → einen) |
| Dativ article change? | m/n=**dem**, f=**der**, pl=**den+n** |
| helfen, danken, gehören → Case? | **Dativ** |
| Person & Thing word order? | Person (Dat) BEFORE Thing (Akk) |
