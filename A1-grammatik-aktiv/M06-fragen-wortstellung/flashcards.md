# Module 06 — Flashcards: Fragen & Wortstellung

---

## Question Words

| Front | Back |
|---|---|
| who? | **wer** |
| what? | **was** |
| where? (static) | **wo** |
| where from? | **woher** |
| where to? | **wohin** |
| when? | **wann** |
| why? | **warum** |
| how? | **wie** |
| how old? | **wie alt** |
| how many? | **wie viele** |

---

## Sentence Patterns

| Front | Back |
|---|---|
| W-question pattern | W-Word + **Verb** + Subject + Rest |
| Yes/No pattern | **Verb** + Subject + Rest + ? |
| Statement pattern | Subject + **Verb** + Rest |
| Statement with time first | Time + **Verb** + Subject + Rest |

---

## Verb Position

| Front | Back |
|---|---|
| Where is the verb in statements? | Position **2** (always!) |
| Am Montag ___ ich. (arbeiten) | Am Montag **arbeite** ich. |
| Where is the verb in Y/N questions? | Position **1** |
| Where is the verb in W-questions? | Position **2** (after W-word) |

---

## wo / woher / wohin

| Front | Back |
|---|---|
| ___ wohnst du? | **Wo** (static) |
| ___ kommst du? | **Woher** (from) |
| ___ fährst du? | **Wohin** (to) |
