# Module 01 — Flashcards: Personalpronomen

---

## Pronoun Meanings

| Front | Back |
|---|---|
| ich | I (tôi) |
| du | you — informal (bạn) |
| er | he / it for 🔵 der nouns |
| sie (singular verb) | she / it for 🔴 die nouns |
| es | it for 🟢 das nouns |
| wir | we (chúng tôi) |
| ihr | you all — informal (các bạn) |
| sie (plural verb) | they (họ) |
| Sie (capital) | you — formal (quý vị) |

---

## Noun → Pronoun (Things)

| Front | Back |
|---|---|
| der Löffel → ? | **er** (🔵 Mask.) |
| die Gabel → ? | **sie** (🔴 Fem.) |
| das Messer → ? | **es** (🟢 Neut.) |
| der Tisch → ? | **er** |
| die Lampe → ? | **sie** |
| das Buch → ? | **es** |
| der Kaffee → ? | **er** |
| die Tasche → ? | **sie** |
| das Handy → ? | **es** |

---

## Tricky Cases

| Front | Back |
|---|---|
| das Mädchen → ? | **es** (NOT sie! -chen = Neutral) |
| die Kinder → ? | **sie** (Plural = always sie) |
| die Bücher → ? | **sie** (Plural) |

---

## sie / sie / Sie

| Front | Back |
|---|---|
| sie + singular verb | **she** |
| sie + plural verb | **they** |
| Sie (capital S) | **formal you** |
